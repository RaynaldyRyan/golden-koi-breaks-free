A golden koi bursts out of a Japanese scroll painting hanging in a museum
gallery, water exploding from the canvas onto the polished floor as stunned
visitors watch. The painting's ink world spills into the real one — the fish
is no longer inside the art, it is loose in the room.

`main.ts` copies `entry.png` byte-for-byte into `$MAKEFUN_OUTPUT_DIR` so the
judge sees exactly this image.
